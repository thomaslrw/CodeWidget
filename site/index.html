FAQ

  

    
Is it free?
Yes. It's free and open source under the MIT licence. The code is on GitHub.

    
Which computers does it work on?
Mac (Apple silicon and Intel), Windows and Linux. The download button picks the right one for you.

    
Does it work on my phone?
No. CodeWidget is for desktop computers. Phones only let App Store apps put widgets on the home screen.

    
Why does my computer warn me the first time?
CodeWidget isn't signed by Apple or Microsoft yet, so your computer asks you to confirm once. "First time opening it?" above shows where to click.

    
Is it safe to paste code from other people?
Widget code runs in a sandbox, like a web page. It can't read your files, run commands or use your camera or microphone. Only paste code you'd be happy to run in a browser.

    
What code works?
One HTML file with its CSS and JavaScript inside. Code copied straight from an AI chat works, even with the ``` marks around it.
